# taste-skill: Anti-Slop Frontend & High-End Design System

Master skill for the `Leonxlnx/taste-skill` suite. Provides anti-slop heuristics, elevated visual taste, motion engineering, and design systems for landing pages, web applications, and brand identities.

## Available Specialized Skills in this Suite

When invoked or handling frontend design tasks, refer to the individual specialized modules:

1. **`design-taste-frontend`**: Anti-slop frontend guidelines for landing pages, portfolios, and redesigns. Prevents generic AI layouts and defaults.
2. **`gpt-taste`**: Awwwards-level frontend design engineering, GSAP animations (scroll triggers, pinning, scrub), custom typography (Satoshi, Cabinet Grotesk, Outfit, Geist), and AIDA layout structure.
3. **`high-end-visual-design`**: Refined editorial aesthetics, luxury/minimal visual rules, and sophisticated color theory.
4. **`minimalist-ui`**: High-clarity, minimal interfaces with ample whitespace, restrained palettes, and precise typographic hierarchy.
5. **`industrial-brutalist-ui`**: Bold, high-contrast, structural brutalist styling with technical grids and monochrome accents.
6. **`brandkit`**: Premium brand guidelines boards, logo system generation, identity decks, and visual-world presentations.
7. **`stitch-design-taste`**: Component-level cohesion, seamless aesthetic stitching, and harmonious UI integration.
8. **`redesign-existing-projects`**: Auditing and elevating existing codebases without breaking existing business logic.
9. **`image-to-code`**: Converting visual mockups, wireframes, and screenshots into production-ready frontend components.
10. **`imagegen-frontend-web` / `imagegen-frontend-mobile`**: Art-directed asset generation for web and mobile hero sections and UI cards.
11. **`full-output-enforcement`**: Ensuring complete, unabridged, production-ready code outputs without placeholders or ellipses.
